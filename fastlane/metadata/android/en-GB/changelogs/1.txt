Initial release of ClearNet FOSS
- Content-control app built with Flutter.
- Uninstall protection via safe Device Admin rules.
- Offline custom domain & keyword website blocklist filtering.
- Local VPNService filters DNS lookups on the device.
- SafeSearch enforcement for Google, Bing and YouTube.
- Blocklist JSON import/export & custom DNS support.
- Interactive disable confirmation security challenge.
- Privacy-focused: no remote cloud accounts, trackers or ads.
