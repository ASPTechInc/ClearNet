# [v1.0.0](https://github.com/ASPTechInc/ClearNet/tree/v1.0.0) (2026-09-09)

Full stable release of ClearNet, a free and open-source (FOSS) parental control application built with Flutter.

### Features

- **Uninstall Protection**: Registers securely as a Device Admin to block unauthorized uninstalls without a valid parent PIN.
- **App Restriction**: Seamless restriction of selected applications from being launched.
- **Local Network Filtering**: Built-in high-performance local VPNService to intercept and filter malicious adult domains.
- **Privacy-First Architecture**: No cloud requirements, no telemetry analytics trackers, and zero data gathering.
- **Offline blocklist**: Embedded JSON-based adult domain blocklist preloaded straight within app assets.
- **Custom Filters**: Empower parents to append customized domains or exceptions directly to the local blocklist.
- **Automated Workflow Layouts**: Refactored complete GitHub Action runners for rapid Lint, Test, and Releases.
- **FOSS Ready**: Open-source transparency under the highly permissive MIT license.
